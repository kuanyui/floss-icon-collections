# floss-icon-themes
Collection of some existed tango-flavoured icon theme packs taken from some FLOSS apps.

Mainly be used in [tango-icon-remixer](https://github.com/kuanyui/tango-icon-remixer/)

# Pack List
## GIMP
- [repo](https://gitlab.gnome.org/GNOME/gimp-data/-/tree/main/icons?ref_type=heads)
- Icon Pack
  - `GimpLegacy` (GPL v3+, licensed the same as GIMP application core)
  - `GimpDefault` (CC by-sa 3.0)

## Inkscape
- [repo](https://gitlab.com/inkscape/inkscape/-/tree/master/share/icons?ref_type=heads)
- Icon Pack
  - `InkscapeTango` (GPL v2)
